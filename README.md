# CV-TOOL // SYSTEM_CORE

> **STATUS:** OPERATIONAL  
> **PROTOCOL:** DEEP_ANALYSIS & RECONSTRUCTION  
> **ENCRYPTION:** ACTIVE  

CV-TOOL is a specialized AI utility engineered for deep CV analysis and high-fidelity resume reformulation. It treats career data as raw input to be parsed, optimized, and reconstructed into high-impact professional documentation.

## [CORE_SPECIFICATIONS]

### // MULTI-PERSONA_ANALYSIS
Analysis driven by three distinct AI analytical cores:
- **[ATS_ENGINE]:** Technical parsing, keyword optimization, and structural validation.
- **[CAREER_HISTORIAN]:** Trajectory mapping and narrative consistency analysis.
- **[THE_STRATEGIST]:** Impact quantification and competitive value positioning.

### // GROWTH_PROTOCOL
Dynamic delta-analysis between user qualifications and job requirements. Generates actionable skill acquisition matrices and development roadmaps to bridge professional gaps.

### // HIGH-FIDELITY_GENERATION
Deterministic transformation of raw experience into "American Model" resumes. Engineered for maximum quantifiable impact and technical precision.

### // PROFESSIONAL_EXPORT
Optimized PDF output via `@react-pdf/renderer`. Validated for both machine parsers and human executive review.

## [TECH_STACK]

- **KERNEL:** Next.js 16 (App Router)
- **AI_LAYER:** Vercel AI SDK
- **DATA_STORE:** Prisma + SQLite
- **VISUAL_INTERFACE:** Tailwind CSS 4
- **OUTPUT_ENGINE:** @react-pdf/renderer

## [DESIGN_PHILOSOPHY]

**TERMINAL INDUSTRIAL / BRUTALIST-MINIMALISM**
- High-density, data-centric interface.
- Monochromatic palette: `#131313` (Surface) with `#FFB300` (Amber) functional accents.
- Sharp 90° geometry and 1px borders.
- Typography: JetBrains Mono / Hanken Grotesk.
