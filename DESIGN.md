# Design System: Terminal Industrial / Brutalist-Minimalism

## Core Aesthetic
- **Aesthetic**: Terminal Industrial / Brutalist-Minimalism.
- **Color Palette**: Neutral dark mode (Surface: #131313, Primary Accent: #FFB300 / Amber).
- **Typography**: JetBrains Mono for code/data, Hanken Grotesk or Terminess Nerd Font for headlines.
- **Geometry**: Sharp 90-degree corners, 1px borders, high-density grids.
- **Atmosphere**: Focused, professional, technical, and data-driven.

## UI Elements
- **Borders**: 1px solid #333333.
- **Buttons**: Sharp corners, amber text/border, fills on hover.
- **Inputs**: Dark background, amber focus border.
- **Grids**: High-density layouts, clear divisions.
